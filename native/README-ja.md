# OLED_OFF

Windowsのモニターを、好きなキーボードショートカットから消灯します。

OLED_OFF v1.0.0 / Windows 10・11 x64向け。EXEは未署名です。

## 設定

1. ZIPを展開し、`Setup.exe` を使い続ける場所に置きます。
2. `Setup.exe` をダブルクリックします。
3. 初期設定の **Ctrl+Shift+F12** を使う場合は、そのまま「ショートカットを作成」をクリックします。
4. 別のキーを使う場合は「キーを変更」をクリックし、使いたいキーを同時に押して離します。例えば Ctrl と Shift を押しながら F10 を押すと `Ctrl+Shift+F10` が表示されます。その後「ショートカットを作成」をクリックします。

設定画面を閉じてから、登録したキーを押すと消灯します。デスクトップショートカットのダブルクリックでも使えます。

入力中は Esc または「入力をキャンセル」で取り消せます。アプリがフォーカスを失った場合も入力を取り消します。「既定に戻す」で Ctrl+Shift+F12 に戻せます。変更は保存ボタンを押すまで反映されません。

初期設定は **Ctrl+Shift+F12** です。Ctrl または Alt と、F1～F12・英字・数字を組み合わせます。Shiftも追加できます。Windowsキーは指定できません。他のアプリと同じキーを使っている場合は、別のキーを選んでください。

## 変更・削除

- キーを変更するには `Setup.exe` を再実行してください。現在のキーが表示されます。「キーを変更」で別のキーを選び、「変更を保存」をクリックします。
- 更新版で「設定を更新」が表示された場合は、クリックすると現在のキーを維持してアイコンとショートカットを更新します。
- 設定後はEXEを移動・削除しないでください。移動した場合は、デスクトップショートカットを削除し、移動先で設定し直してください。
- アンインストールは、デスクトップショートカットとEXEを削除します。
- ショートカットのアイコンは自動で `%LOCALAPPDATA%\OLED_OFF\icons` に保存します。アンインストール後は、このフォルダーも削除できます。
- 同名の別のショートカットがある場合は、画面内に対処方法を表示します。「デスクトップを開く」から既存のものを移動または名前変更し、アプリを開き直してください。

## 動作

- Windows 10/11の64ビット（x64）向けです。PowerShellや追加のランタイムのインストールは不要です。
- 管理者権限は不要です。常駐せず、呼び出したときだけ動作します。
- PC本体のスリープ・ロックは行いません。接続した複数のモニターに消灯要求を送ります。
- 通常はキーボードやマウス入力で再点灯します。すぐ再点灯する場合は入力機器などの影響も確認してください。
- キーを離すために500ミリ秒待ってから消灯を要求します。
- キーの有効化に時間がかかる場合は、少し待って再試行してください。
- 通常の起動は設定画面、`Setup.exe --off` は消灯処理です。セットアップでは画面を消灯しません。
